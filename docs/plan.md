# 實作計畫：《機械錶怎麼走：一頁互動圖解》

**目標：** 依 `SPEC.md` 做出單一 `index.html`，四章都有可操作的 SVG 互動。

**架構：** 一個 HTML 檔，分成三塊：`<style>`（色票 token、版面）、各章的 HTML 骨架（文字、按鈕、空的 `<svg>`）、一個 `<script>`。程式依序是：`DATA`（所有官方數字）→ 共用工具（建 SVG 元素、齒輪路徑、補間、按住按鈕）→ 每章一個 `init` 函式 → 一個共用的 `requestAnimationFrame` 迴圈，只更新畫面上看得到的章節。第 1 章和第 2 章共用同一個 `power` 狀態，所以在錶冠第 1 段上鍊，會反映到第 2 章的動力儲存。

**工具：** HTML／CSS／原生 JS；檢查和截圖用 Playwright（借原專案 `node_modules` 裡的版本，Edge 通道），腳本放在 `tests/check.mjs`。
